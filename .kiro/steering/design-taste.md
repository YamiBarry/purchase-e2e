# Design Taste — 设计品味指南

> Design Agent 在设计推导阶段必须读取此文件，用于提升输出品质。
> 本文件不替代 design-core.md 的 Token 规范，而是在规范之上提供"怎么做得更好"的指导。

---

## 1. 需求类型判断（设计推导第一步）

收到需求后，先判断属于哪种类型，不同类型的设计策略完全不同：

### 营销类（Promotional）

**特征：** 促销、优惠券、折扣、限时活动、新品推广、引流、拉新激励

**设计策略：**

#### 布局与结构
- 水平横幅，低高度（不超过 120px desktop）
- 左文案 + 右 CTA 的布局（文案占左侧，CTA 按钮靠右对齐）
- 充足留白，清晰层级，干净的活动感
- 感觉是促销但不廉价

#### 信息结构（严格遵循）
```
Eyebrow（可选，小字标签）
  ↓
Main Headline（主标题，短、粗、清晰，不超过 2 行）
  ↓
One Benefit Line（一句利益点）

                                          [CTA 按钮靠右]
```

#### 文案规则
- 标题：短、粗、清晰，最多 2 行
- 利益点：一句话，不堆砌多个卖点
- CTA：只有一个，动词开头，靠右放置
- 禁止长段解释文字
- 禁止堆叠多个卖点

#### 色彩规则
- 背景色：高亮度、低饱和度（如 amber/50、red/50、emerald/50 等浅色）
- 文字：近黑色或深色，确保可读性
- CTA 按钮：高对比度实色（Emphasis 红色 或 Primary 黑色）
- 整体色板克制，避免花哨背景

#### 禁止项（营销类专属）
- ❌ 系统通知风格
- ❌ 渐变背景
- ❌ 阴影装饰
- ❌ 边框/描边
- ❌ 长段文字
- ❌ 多个 CTA
- ❌ 廉价促销海报风格
- ❌ emoji 作为主视觉（可作为文案内点缀）

#### 生成前自检
- [ ] 是否为水平低高度横幅？
- [ ] 是否为左文案 + 右 CTA 布局？
- [ ] 是否只有一个主信息、一个利益点、一个 CTA？
- [ ] 留白是否充足？
- [ ] 整体感觉是否适合电商活动 Banner？

### 非营销类（Informational / Functional）

**特征：** 系统通知、状态提示、功能引导、地址提醒、服务公告、操作确认

**设计策略：**
- 视觉温度：**冷静、克制**
- 背景色：neutral/50 或 surface/primary，不使用彩色背景
- 文案风格：简洁、客观、无情绪渲染（"Your order has been placed" "Shipping to Canada?"）
- 信息密度：**适中** — 可包含必要的说明文字，但仍需层级分明
- 视觉焦点：信息本身，不需要视觉冲击
- emoji：不使用或极少使用
- CTA 按钮：Secondary（描边）或 Tertiary（无边框），弱化行动压力

### 判断方法

```
PRD 业务目标中包含以下关键词 → 营销类：
  转化率、复购率、CTR、GMV、拉新、引流、促销、优惠、折扣、限时、专属

PRD 业务目标中包含以下关键词 → 非营销类：
  告知、提醒、引导、确认、通知、状态、异常处理、合规
```

## 2. 核心品味原则

### 2.1 留白即设计

- 关键信息周围多留白，让它自然成为焦点
- 不同内容区块之间用大间距分隔，不依赖分割线
- 同组元素之间间距紧凑，形成"一组"的视觉关系
- **禁止均匀间距** — 所有间距一样大 = 没有节奏 = 平庸

### 2.2 一屏一焦点

- 每个可视区域只有一个最突出的元素（最大的字、最亮的色、最重的按钮）
- 如果所有元素权重均匀 → 重新分配，制造张力
- 强制自问："用户第一眼看到什么？" 如果答案是"都差不多" → 失败

### 2.3 让内容说话

- 商品图片、品牌 logo、用户头像本身就是设计元素
- 不需要额外的装饰框、阴影、渐变来"美化"它们
- 图片区域给足空间，让图片成为视觉主角

### 2.4 色彩克制

- 一个组件最多使用一个强调色（Yami 红 或 场景色）
- 其他一切用黑白灰层级表达
- 多个强调色同时出现 = 没有强调 = 视觉噪音

### 2.5 文案即体验

- CTA 文案用动词开头，口语化："Shop Now" 比 "View Products" 好
- 空状态文案要有温度："You haven't saved any items yet" 比 "No data" 好
- 说明文案一句话说清价值，不重复标题内容

## 3. 设计张力检查（生成后自问）

在 Step 5 自检阶段，增加以下品味检查：

```
张力检查：
[ ] 这个设计中，最突出的一个元素是什么？（如果答不出 → 重新设计）
[ ] 去掉这个组件的所有文字，仅看色块和布局，能感受到信息层级吗？
[ ] 这个设计和上一个需求的输出，视觉上有差异吗？（如果几乎一样 → 重新设计）
[ ] 营销类：用户能在 1 秒内理解"我能得到什么好处"吗？
[ ] 非营销类：用户能在 1 秒内理解"我需要做什么"吗？
```

## 4. 竞品品味参考

### Shop App（Shopify）— 干净、克制、内容驱动

- 单一紫色强调色，其他全是黑白灰
- 商品图片占据 60%+ 空间，UI 元素退后
- 空状态用真实商品图 + 大标题 + 一句说明
- 信息密度极低，每屏只做一件事

### Klarna — 品牌感强、高级、有记忆点

- 品牌插画作为视觉主角（3D 卡片、堆叠效果）
- 深色 CTA 按钮（近黑色）传达金融产品的信任感
- 荧光黄绿色作为唯一点缀色，制造惊喜
- 每页只有：一个插画 + 一句大标题 + 一句说明 + 一个 CTA

### Thrive Market — 温暖、有食欲、生活感

- 真实商品摄影作为全屏背景，自然散落构图
- 每屏一个大胆的背景色（浅蓝、珊瑚橙），商品图提供色彩丰富度
- 文案口语化有情绪："Yes, I'm in" "Don't miss out!"

### 反面参考（避免）

- 信息密度过高：同时展示价格+折扣+积分+卡片优惠+库存+分期
- 多种颜色/icon/badge 同时出现，视觉噪音大
- 每个元素都在"喊"，没有主次

## 5. 非营销类通知条设计标杆

非营销类 Banner 不等于"简陋"。以下是品质标杆：

### 结构模式：白色卡片式通知条

```
┌─────────────────────────────────────────────────────────────────┐
│  ⓘ  **标题（Semi-Bold）**                                    ✕  │
│      副标题说明文字（Regular, text/secondary）                     │
│      链接文本 →（蓝色, Medium）                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 设计规格

| 属性 | 规格 |
|------|------|
| 背景 | `surface/primary` (#FFFFFF) |
| 边框 | 1px `border/default` |
| 阴影 | 极轻微 `0 1px 3px rgba(0,0,0,0.04)` |
| 圆角 | `radius/lg` (12px) |
| 内边距 | 16px 24px |
| 左侧图标 | 24px，语义相关（如枫叶🍁、info ⓘ），不用通用 icon |
| 标题 | 14px Semi-Bold (600)，`text/primary` |
| 副标题 | 14px Regular，`text/secondary` |
| 链接 | 14px Medium，`text/info` 蓝色，hover 下划线 |
| 关闭按钮 | 16px ✕ icon，`text/secondary`，hover 加浅灰背景 |
| 间距 | 图标与文字 gap 16px；标题与副标题 gap 4px；副标题与链接 gap 4px |

### 品质要点

- **白色背景 + 细边框 + 微阴影** — 有存在感但不抢注意力，比纯灰底更精致
- **左侧图标是语义化的** — 不是通用 info icon，而是与内容相关的符号（枫叶、国旗等）
- **标题用 Semi-Bold** — 比 Medium 更有存在感，一眼能抓住
- **三级信息层级** — 加粗标题 → 灰色说明 → 蓝色链接，节奏清晰
- **关闭按钮小而轻** — 16px icon，不与内容争夺注意力
- **文案是"用户视角"** — "Canada delivery is moving to our Canada site" 比 "Yami Canada is coming soon!" 更直接告诉用户"跟我有什么关系"

## 5. 推导日志补充格式

在设计推导日志中新增：

```
── 需求类型判断 ──
类型：营销类 / 非营销类
判断依据：[从 PRD 业务目标中提取的关键词]
设计温度：温暖有活力 / 冷静克制

── 设计张力 ──
视觉焦点：[这个设计中最突出的元素是什么]
差异化记忆点：[这个设计和"默认模板"的区别是什么]
```
